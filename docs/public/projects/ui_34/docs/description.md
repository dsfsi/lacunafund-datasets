This project creates a time-aligned, annotated audio-visual dataset specifically focused on the tonal features of African languages. It addresses a critical gap in NLP, as tone—a fundamental linguistic feature—is often omitted from datasets, severely hampering the development of accurate speech and language technologies for these languages. The dataset includes both elicited words and natural conversations across different language varieties. Openly available, this resource is invaluable for linguists, speech technology researchers, and language revitalization teams. It enables the development of tone-aware speech recognition and synthesis systems, which are essential for creating truly effective and natural digital tools for the hundreds of millions of speakers of tonal languages in Africa.
