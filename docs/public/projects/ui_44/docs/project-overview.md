# Machine Learning Dataset for Rabies Diagnosis and Outbreak Prediction

## Overview
This dataset will help in the real-time and remote diagnosis of rabies disease for humans and animals in low-resource settings. A time series approach can be applied to the outbreak dataset to predict the number of rabies cases likely to occur within an area after a given time interval. This approach can help with resource mobilization, too, such as identifying the number of vaccines required in a specific area at a given time.

## Technical Details
The dataset comprises three separate components:
- **Animal diagnosis dataset**: 7,081 observations
- **Human diagnosis dataset**: 4,585 observations  
- **Outbreak prediction dataset**: 1,018 observations
