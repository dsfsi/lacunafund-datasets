# Machine Translation Benchmark Dataset for Languages in the Horn of Africa

## Overview

This evaluation dataset automatically quantifies the quality of machine translation systems for five languages from the Horn of Africa region: Afar, Amharic, Oromo, Somali and Tigrinya. The dataset provides a standardized benchmark for evaluating machine translation performance across these under-resourced African languages.


## Technical Details

This benchmark dataset enables:
- Automated evaluation of machine translation quality
- Standardized comparison across different MT systems
- Performance assessment for low-resource African languages
- Research advancement in Horn of Africa language technologies
