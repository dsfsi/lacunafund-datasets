Dataset: KenSwQuAD – A Question Answering Dataset for Swahili Low Resource Language

Country/Region: Kenya

Description:
This project produced a large Machine Reading Comprehension dataset for the Kiswahili Language. A total of 7,526 Question-Answer (QA) pairs were developed based on 1,445 Swahili story texts.

Authors:
Barack Wanjawa, Lawrence Muchemi (University of Nairobi), Lilian D.A. Wanzare, Florence Indede, Owen McOnyango (Maseno University), Edward Ombui (Africa Nazarene University)
