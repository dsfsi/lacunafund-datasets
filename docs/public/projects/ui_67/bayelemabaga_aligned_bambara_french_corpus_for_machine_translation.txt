Dataset: Bayelemabaga Aligned Bambara-French Corpus for Machine Translation

Country/Region: Mali/France

Description:
The Bayelemabaga dataset consists of 46,976 parallel machine translation-ready Bambara-French sentence pairs, originating from the Bambara Reference Corpus from INALCO's LLACAN Lab. The text is extracted from 264 text files.

Authors:
Allahsera Auguste Tapo, Michael Leventhal, Valentin Vydrin, Sebastian Diarra, Marcos Zampieri, Emily Prud'Hommeaux, Jean Jacque Méric, Christopher Homan (Multi-institutional collaboration)
