Ethio Speech Corpora comprises over 391 hours of recorded audio in six Ethiopian languages: Amharic (68 hours), Tigrigna (62 hours), Oromo (70 hours), Somali (56 hours), Afar (68 hours), and Sidama (68 hours). This project is a valuable resource for developing well-performing automatic speech recognition (ASR) systems for these languages in monolingual, multilingual, and cross-lingual setups. Use cases include dictation systems, transcription systems, assistive technologies, spoken dialogue systems, speech translation, and other speech technologies. The dataset maintains gender and age balance of readers across six working languages used across regional states of Ethiopia.
